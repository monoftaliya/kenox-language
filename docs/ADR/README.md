# Architecture Decision Records — KENOX

> Версия 0.4 · 5 ноября 2026

ADR — короткая запись одного архитектурного решения: какая была проблема, какие рассматривались варианты, что выбрано и почему. Актуальная сводка архитектуры — [ARCHITECTURE.md](../ARCHITECTURE.md); подробный анализ — [ARCHITECTURE_REVIEW.md](../ARCHITECTURE_REVIEW.md); нерешённые вопросы — [OPEN_QUESTIONS.md](../OPEN_QUESTIONS.md).

## Статусы

| Статус | Значение |
|---|---|
| **предлагается** | Рекомендация готова; серьёзных возражений не ожидается. Можно утверждать пакетом |
| **требует утверждения** | Спорное решение с заметными компромиссами; нужен явный выбор |
| **отложено** | Решать позже; сейчас фиксируются только ограничения на дизайн |
| **принято** | Утверждено. Изменения — только новым ADR, который заменяет старый |
| **заменено** | Заменено другим ADR (указывается номер) |
